# SetClick — セトリ・メトロノーム

セトリごとに曲のテンポを保存して、曲をタップするだけでその BPM で鳴らせるメトロノーム（PWA）。

**▶ https://isojz.github.io/setclick/**

## できること
- **複数セトリ**：上部のタブで切り替え（セトリ1＝曲1,2,3… ／ セトリ2＝曲4,5,6…）
- **曲をタップで即再生**：もう一度タップで停止、別の曲をタップで即切り替え。◀▶ で前後の曲へ
- **拍子**：2/4〜7/4、5/8・6/8・7/8・9/8・12/8
- **ミキサー**：1拍目／表／8分裏／3連／16分を縦フェーダーで個別に音量調整（6/8 系は 8分／16分）。名前タップでオン/オフ、複数同時に鳴らせる。再生中にプレイヤーで動かして「保存」で曲に記録
- **再生中の ± 微調整**：その場でテンポを変えて、よければ「保存」で曲に反映
- **TAP テンポ**・**フリーモード**（セトリと無関係に鳴らす）
- **1小節／2小節で自動停止**：テンポを耳に入れてからカウントを出す用
- **画面フラッシュ**・再生中はスリープしない
- **まとめて追加**：「曲名 BPM [拍子] [裏]」を1行ずつ書いて一括登録
- **共有リンク**でセトリをメンバーに送れる／**JSON バックアップ**
- オフラインで動く（ホーム画面に追加推奨）

## 使い方のコツ
- iPhone は「共有 → ホーム画面に追加」して使う（Safari のままだと7日使わないとデータが消えることがある）
- ホーム画面アプリに共有リンクを取り込むときは、リンクを開かずに「＋ セトリ」→「共有リンクから取り込む」に貼り付け
- キーボード（PC）：Space 再生／停止、←→ 曲送り、↑↓ テンポ
